# Masho Portfolio

Personal portfolio for Parvez Al Mumin (Masho).

## Run locally
1. Extract this ZIP file.
2. Open the `masho-portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Folder structure
- `index.html` — website content
- `css/style.css` — styling, themes and responsive layout
- `js/script.js` — menu, themes, scroll effects
- `assets/images/` — `parvez-al-mumin.jpg` (profile photo) and `masho-logo.png` (Masho logo)
- `assets/icons/` — technology logos

## Changing certificate links
In `index.html`, find the Certifications section. Each card has a button like:

    <a class="btn cert-btn" href="PUT-LINK-HERE" target="_blank" ...>

Replace the `href` value with a Google Drive link or a credential URL. It opens in a new tab.

## Themes
Five theme buttons are in the navbar (Dark, Light, Dark Purple, Green, Red). To change colors, edit the `[data-theme="..."]` blocks at the top of `css/style.css`.

## Before publishing
